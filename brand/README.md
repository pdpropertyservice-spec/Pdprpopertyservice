# Pav's Window Co. logo kit

A clean four-pane window mark and a plain, heavy wordmark, in forest green and brushed silver.

All files in `brand/logo/` are vector (SVG) with the lettering converted to outlines, so a
printer, sign shop, or embroiderer can open them without installing fonts. `brand/logo/png/`
has transparent PNG exports at 2000px wide. `variants-sheet.png` shows each file on its
intended background and `mockups.png` shows the logo on a card, a van, and shirts.

## Files

| File | Use it for |
| --- | --- |
| `mark-*` | The window on its own: favicon, hats, small embroidery, social avatars |
| `logo-horizontal-*` | Website header, business card front, vehicle doors |
| `logo-line-*` | One-line version for narrow strips, email signatures, invoices |
| `logo-stacked-*` | Square spaces: profile images, shirt chest, stickers, van rear |
| `badge-*` | Round version with a thin ring: shirt backs, decals, stamps |
| `icon-tile.svg`, `png/icon-tile-*.png` | Favicon and phone home-screen icon |

Four tones of each:

- `night`: silver frame, green glass, silver name. For dark backgrounds. The primary version.
- `day`: green frame, silver glass, green name. For white or light backgrounds.
- `mono-white`: one color, white. For vinyl, screen printing, or embroidery on dark material.
- `mono-black`: one color, black. For stamps, engraving, and light vinyl.

## Colors

| Name | Hex | Where |
| --- | --- | --- |
| Forest | `#0B3D2A` | Glass on dark, frame and name on light |
| Forest deep | `#06271B` | Shadow end of the green gradient |
| Forest light | `#14503A` | Highlight end of the green gradient |
| Green mid | `#1E7A52` | "Window Co." on light backgrounds |
| Green light | `#7CCBA6` | "Window Co." on dark backgrounds |
| Silver | `#D8DEE1` | Name on dark backgrounds; frame gradient runs `#A9B5BB` to `#FFFFFF` |
| Night | `#070B09` | Website and card background |

For one-ink or one-thread jobs: Forest `#0B3D2A` is close to Pantone 3435 C. The silver
prints well as Pantone 877 C (metallic) or Cool Gray 3 C (flat).

## Fonts

- Name: Manrope ExtraBold (free, Google Fonts)
- "Window Co.": Manrope Bold, letter-spaced (free, Google Fonts)

## Rules of thumb

- Keep clear space around the logo of at least half the window's width.
- Don't stretch, recolor, rotate, or add effects. Use `day` on white and the mono versions
  when only one color is available.
- Minimum size: horizontal logo at least 1 inch wide in print; the window alone works down
  to 0.3 inch, and 16px on screen.

The kit is generated by a script, so changes can be reapplied across every variant at once.

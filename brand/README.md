# Pav's Window Co. logo kit

A shield crest in forest green and brushed silver. A squeegee has wiped the top of the
glass clean, leaving silver above the blade and deep green below it.

Everything in `brand/logo/` is vector (SVG) with all lettering converted to outlines, so a
sign shop, printer, or embroiderer can open it without installing fonts. `brand/logo/png/`
holds transparent PNG exports at 2000px wide. `variants-sheet.png` shows every file on its
intended background and `mockups.png` shows the logo on a card, a van, and shirts.

## Files

| File | Use it for |
| --- | --- |
| `mark-*` | The shield on its own: favicon, hats, small embroidery, social avatars |
| `logo-horizontal-*` | Website header, business card front, vehicle doors, email signature |
| `logo-stacked-*` | Square spaces: profile images, shirt chest, stickers |
| `crest-*` | Shield with the name inside and a ribbon banner: shirt backs, van rear, signs |
| `seal-*` | Round seal with ring text and phone number: shirt backs, decals, stamps |
| `icon-tile.svg`, `png/icon-tile-*.png` | Favicon and phone home-screen icon |

Each design comes in four tones:

- `night`: full color on dark backgrounds. The primary version for the website and shirts.
- `day`: full color on white or light backgrounds. For cards, paper, and white vehicles.
- `mono-white`: one color, white. For vinyl, screen printing, or embroidery on dark material.
- `mono-black`: one color, black. For stamps, engraving, faxes, and light vinyl.

## Colors

| Name | Hex | Where |
| --- | --- | --- |
| Forest | `#0B3D2A` | Lower shield, handle, name on light backgrounds |
| Forest deep | `#06271B` | Shadow end of the green gradient |
| Forest light | `#15563B` | Highlight end of the green gradient |
| Green mid | `#1E7A52` | "Window Co." on light backgrounds |
| Green light | `#6FC39B` | "Window Co." on dark backgrounds |
| Silver | `#AEB9BF` to `#FFFFFF` | Upper shield, rim, blade, name on dark backgrounds |
| Night | `#070B09` | Website and card background |

For vendors who need one ink or thread color: Forest `#0B3D2A` is close to Pantone 3435 C
and the silver reads well as Pantone 877 C (metallic) or Cool Gray 4 C (flat).

## Fonts

- Name: Barlow Condensed Bold (free, Google Fonts)
- "Window Co." and small text: Barlow Bold (free, Google Fonts)

## Rules of thumb

- Keep clear space around the logo of at least half the shield's width.
- Don't stretch, recolor, rotate, or add effects. Use the mono versions when color isn't
  available, and the `day` versions on white.
- Minimum size: the horizontal logo at least 1.25 inches wide in print; the shield alone
  works down to 0.4 inch, and 16px on screen.

The kit is generated by a script, so changes to the shape or text can be reapplied across
every variant at once.
